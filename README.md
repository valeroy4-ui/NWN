# Cormyr — NWN project

Присланные исходники и инструменты для разработки карты мира в Neverwinter Nights: Enhanced Edition.

- `source/` — полное содержимое архива `__loc_var_info__.zip` и три шаблона предметов `.uti`.
- `patches/received-test-server/` — отдельно присланные тестовые версии модульных скриптов. Они отличаются от одноимённых файлов в `source/` и сохранены отдельно. Это полученные материалы, а не установленный или готовый к установке патч.
- `tools/nwnsc` — присланный Linux-компилятор; совпадает с копией из `tools.zip`. Не запускался.
- `compose.yaml` — конфигурация тестового сервера; значения паролей заменены ссылками на переменные окружения. Локально создайте `.env` по `.env.example` и заполните своими значениями.
- `docs/received-files.json` — размеры, источники и SHA-256 полученных файлов.

Текущее состояние и недостающие ресурсы перечислены в [PROJECT_STATE_RU.md](PROJECT_STATE_RU.md).

## Важно для сборки

Некоторые присланные пары `.nss`/`.ncs` не соответствуют друг другу. Перед установкой требуется корректная пересборка с зависимостями. В `source/` есть файлы в CP1251; их исходные байты сохранены.

Этот репозиторий ещё не является полностью собираемым и запускаемым сервером: не получены модуль `.mod`/`module.ifo`, области и полный комплект серверных ресурсов. Docker Compose использует абсолютные пути машины владельца.
