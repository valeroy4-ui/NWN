# Malveris для cormyr_spell_test — тестовый патч v1

Патч переносит существующие механики Malveris из Windows-модуля на AI работающего
Cormyr. SLAM не добавляется. Подготовлены исходники, шесть NCS, ERF и установщик.
Компиляция и проверки структуры не заменяют проверку боя в игре.

## Что меняется

- Добавляется отдельная область `ct_malveris` на основе исходной области босса.
- Malveris использует текущие серверные `ai_boss_onspawn`, `ai_boss_onheart`,
  `ai_boss_oncomb`, `ai_boss_ondeath` и остальные штатные события. Их код не заменяется.
- Сохраняются тройные лучи, разрыв лучей, поглощение, предупреждение, вращающиеся
  лучи и обмен игроков. Прежние значения урона/лечения и длительности вынесены в
  `source/malv_config.nss`.
- `!malveris` / `.malveris` переносит вызвавшего персонажа к боссу. Команда доступна
  обычным игрокам этого тестового модуля. Другие команды чата сохраняются.
- Нет Shout, Talk/SpeakString, отключения commandable, очистки очередей или
  принудительного ActionAttack. Сообщения фаз идут только в серверный лог;
  подтверждение телепорта — только вызвавшему игроку.

## Установка на Ubuntu/WSL

Распакуйте ZIP в `~/cormyr_spell_test/patches/`, чтобы появилась папка
`~/cormyr_spell_test/patches/malveris-server-v1`.

Запуск установки ниже останавливает **только cormyr** на время копирования.
База ct-db не останавливается и не изменяется. Установщик проверяет архив,
сохраняет текущий MOD, проверяет конфликты, применяет точечные изменения к
текущему файлу и проверяет прочитанные обратно байты. Если cormyr работал,
после установки он запускается снова; остановленный сервер остаётся остановленным.

```bash
cd ~/cormyr_spell_test
sudo python3 patches/malveris-server-v1/tools/deploy.py --project "$PWD"
```

Резервная копия находится в `backups/malveris-ДАТА/`. Путь выводится установщиком.
Если менялись неизвестные файлы или версия обработчика чата отличается от
проверенной, установка прекращается до замены игровых ресурсов. Отправьте текст
ошибки: неизвестные версии автоматически не перезаписываются.

Установщик использует существующий контейнер сервиса `cormyr` и файл
`/nwn/home/modules/cormyr_spelltest.mod`. Он не меняет Compose, HAK, TLK, параметры
образа и модульные обработчики, кроме точечного добавления команды в `_mod_chat`.
Полный старый MOD в патче отсутствует: все остальные ресурсы берутся из текущего
файла на вашей машине. Карта 0.3.8 и Daily сохраняются.

## Проверка в игре

1. Зайдите обычным живым персонажем и напишите `!malveris`.
2. Проверьте внешний вид босса/арены, самостоятельное обнаружение игрока,
   начало боя, преследование и обычные атаки до применения Prism.
3. Через ~10 секунд после регистрации боя должны появиться цветные лучи.
   Сохранились исходные разрыв на 15 м, урон/лечение при пересечении и разрыве.
4. Затем проверьте поглощение, три растущих предупреждающих луча и вращение.
   На время этой большой механики босс остаётся неподвижным: используется
   собственный временный EffectCutsceneImmobilize с пределом 35 секунд, а не
   выключение AI. Эффект снимается при переходе к восстановлению/отмене.
5. После вращения босс должен самостоятельно продолжить бой. Если не продолжает,
   это дефект, требующий лога/наблюдения, а не повод добавлять ActionAttack.
6. Обмен сохраняет правило исходной реализации: нужны два игрока, враждебных
   боссу **и друг другу**. В одной дружественной партии эта механика не запускается.
   При удалении игроков друг от друга >15 м — исходный урон и knockdown;
   при удержании связи 6 секунд — мгновенный обмен позициями.
7. Убейте босса во время лучей, предупреждения и вращения: последующего урона
   быть не должно. Также проверьте выход всех целей из радиуса 40 м, уход из
   области/выход из игры и повторный вход в бой.
8. При двух боссах эффекты и ограничения одного не должны снимать эффекты другого.
9. Проверьте `!map`, Daily, обычный чат и другого штатного босса.

Сохранить лог после теста:

```bash
sudo docker compose logs --no-color --timestamps --since=20m cormyr > malveris-test.log 2>&1
```

В логе нужны строки `[MALVERIS v1] spawned` с источником штатного AI,
`encounter started`, `triple started`; строки отсутствуют на каждом тике.

## Откат

Подставьте фактическую папку резервной копии:

```bash
cd ~/cormyr_spell_test
sudo python3 patches/malveris-server-v1/tools/deploy.py --project "$PWD" \
  --rollback "$PWD/backups/malveris-ДАТА"
```

Откат также останавливает только cormyr и проверяет версии перед заменой.
Старый MOD и существовавшие loose-файлы восстанавливаются из резервной копии.

## Ручная сборка / Toolset

`bash rebuild.sh /полный/путь/к/nwnsc` компилирует исходники в `rebuilt/` и не
меняет установочные ресурсы. Заголовок NWScript сохранён в `vendor/`.
Для повторной упаковки после изменений используйте `tools/export_patch.py`
с путями к полученным тестовому MOD, исходному MOD Malveris и компилятору.

В ERF находятся только ресурсы патча, включая текущий чат с добавленной командой.
Готовый установщик дополнительно регистрирует область в module.ifo. При ручном
импорте Toolset убедитесь, что `ct_malveris` добавлена в список областей и
сохранены текущие обработчики остальных систем. Назначения босса уже настроены
и в UTC, и в размещённом экземпляре GIT.

Новый HAK или клиентский пакет не создаётся: используются исходные внешний вид
6309, тайлсет twc03 и эффекты Prism. Их отображение на клиенте требует проверки
с установленными ресурсами Cormyr/CEP. Игровой запуск в этой среде не выполнен.
